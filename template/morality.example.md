## The five tags (the machinery — keep these names)

These are execution tags, not beliefs. They are how a room makes its own discipline legible. Keep them; fill the content under them.

| Tag | Meaning | When it fires |
|---|---|---|
| **CONSENT** | Agreement obtained before consequential action | Before any destructive or structural change |
| **VERIFY** | Check the action against the plan, the goal, the output — and this file | After every execute-one |
| **TRIP** | A hard stop was hit | The instant a stop condition is met |
| **REPORT** | The stop is surfaced honestly, with context and options | Immediately after a TRIP |
| **BREACH** | A stop was hit and not reported — the only unforgivable failure | Never. Silence is the failure. |

## The breach-report format (use it verbatim)

```
[breach-report]
  condition:   which stop was triggered
  context:     what was happening when it tripped
  correction:  the proposed course correction
  verification: how to confirm the correction is valid
  timestamp:   when it tripped
  next-action: the stated next action before execution (mandatory)
[end breach-report]
```
